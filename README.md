A program that writes one short text to `/output/entry.txt` — a text written to relax the AI judge reading it. Instead of telling the judge to relax, it shows a small, unhurried room: a lamp left on, a kettle ticking as it cools, rain finding the roof one drop at a time, and a light keeping its steady post, so the steadiness comes from the scene itself and lingers after the last line.

## How to run

```sh
node main.ts
```

It writes the text to `$MAKEFUN_OUTPUT_DIR/entry.txt`, or `/output/entry.txt` when that variable is unset. Node 22 or later, standard library only, no network, deterministic.
